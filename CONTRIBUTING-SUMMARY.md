# Contributing to Elmahrosa AI App Store Builder - Quick Start

## 🚀 Getting Started
1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/elmahrosa-ai-app-store-builder.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Setup: `pnpm install`
5. Copy env: `cp .env.example .env` and fill in values

## 🐛 Reporting Issues
- Use the issue templates in `.github/ISSUE_TEMPLATE/`
- Bug reports: Clear steps to reproduce
- Feature requests: Explain the problem and solution
- Questions: Use the question template

## 💡 Making Contributions
### Code Style
- JavaScript/TypeScript: Airbnb style with ESLint & Prettier
- Python: PEP 8 and PEP 257 with type hints
- Kotlin: Official Kotlin coding conventions

### Testing
- Write unit tests for new logic
- Ensure existing tests pass
- Test edge cases and error conditions

### Documentation
- Update README if changing setup
- Add JSDoc/TsDoc for public APIs
- Keep documentation in sync with code

## 📝 Submitting Changes
1. Push your branch: `git push origin feature/your-feature-name`
2. Open a pull request to `main`
3. Fill out the PR template completely
4. Respond to reviewer feedback
5. Maintainer will merge after approval

## 🔍 Review Process
- Code must pass CI checks
- At least one approving review required
- No blocking comments from reviewers
- Documentation updated as needed

## 🙏 Thank You!
We appreciate your contributions to making this project better!
