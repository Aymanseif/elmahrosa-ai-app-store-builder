## Known gaps (honest, not suppressed)

1. **slowapi in-memory limiter** is per-process; a shared Redis backend should replace it when api-core scales horizontally (noted in code).
2. **pip-compile header** records the `--output-file=requirements-hashed.txt` filename it was generated with; regenerate with `-o requirements.txt` on the next refresh to normalize the header.
3. **DB-backed endpoint integration** (e.g. create project → 201 through the full Prisma path) still requires a live database; docker-compose postgres is available but Docker Engine is not present on this verification host. Validation-boundary and auth gates are covered by committed tests.
