# @elmahrosa/ui

Shared UI components for Elmahrosa AI App Store Builder.

## Installation

This is an internal package and is installed via the monorepo's package manager.

## Usage

```tsx
import { Button } from '@elmahrosa/ui';

function App() {
  return <Button>Click me</Button>;
}
```

## Development

To build the package:

```bash
npm run build
```
